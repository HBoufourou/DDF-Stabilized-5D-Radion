# Sources du contrôle de correspondance

Ces trois registres sont des pièces d’audit conservées pour vérifier le traitement des 50 anciennes affirmations et la transition de 27 à 31 affirmations actives. Ils ne définissent aucune version courante supplémentaire et leurs anciens statuts ne valent pas validation.

Le seul registre actif est [registre_revendications.json](../../registre_revendications.json). Le résultat de la comparaison se lit dans [la correspondance](../CORRESPONDANCE_ANCIENS_REGISTRES.csv).

Les anciennes éditions complètes et leurs manuscrits sont sauvegardés localement, hors de l’arbre publié.
