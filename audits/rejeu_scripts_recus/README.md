# Traces du rejeu des scripts reçus

Les six sorties texte servent à contrôler la provenance des corrections. Elles reproduisent les affichages des scripts reçus, y compris les interprétations ensuite corrigées. Elles ne constituent pas six résultats scientifiques automatiquement acceptés.

Lire [le rapport de rejeu](../REJEU_SCRIPTS_RECUS.json) et [l’audit des corrections](../../AUDIT_CORRECTIONS_ET_COMPLETUDE.md). Les scripts originaux et leurs archives sont conservés dans la sauvegarde locale ; les scripts scientifiques actifs et leurs entrées restent dans le dossier publié.
