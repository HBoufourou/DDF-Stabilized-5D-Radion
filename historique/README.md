# Sources historiques — ne pas confondre avec l'état actuel

Ce répertoire conserve les sources examinées avant consolidation. Il contient des déclarations retirées, des verdicts dépassés et des scripts incomplets. Les notes actuelles du noyau et le registre à la racine explicitent leur statut.

- `geometrie_snapshot/` : copie des fichiers texte récupérés au commit indiqué ; pas une copie Git binaire ni l'ensemble des releases.
- `I_VIII_sources_examinees/` : huit articles TeX, annexe et fichiers complémentaires consultés ; copie partielle du dépôt initial.
- `EFT_v3_snapshot/` : contenu scientifique de l'archive v3, sans métadonnées Git ni caches Python.
- `files-ddf_original.zip` : archive utilisateur originale, préservée intégralement.

Les anciennes empreintes de manifests sont conservées comme documents d'origine. Elles ne certifient pas la copie textuelle reconstituée par le connecteur. Le manifest de la racine certifie l'intégrité de cette livraison seulement.
