# Roadmap after R65

| Round | Question | Required output | Stop condition |
|---|---|---|---|
| R66 | Does one real finite DDF geometry show the R65 spectral signature? | locked platform manifest, metric approximation, scalar spectrum, profiles, transverse gap | no convergent 1D packet or unresolved platform mixing |
| R67 | Which geometric eigenvalue is the physical KK/spin-2 observable? | warped operator, normalization, Planck/string/KK dictionary | no controlled operator or inconsistent hierarchy |
| R68 | Can the spectral radius be stabilized rather than selected? | complete effective potential, kinetic matrix, Hessian and sensitivity scan | target fixed by hand or unstable/uncontrolled minimum |
| R69 | Is any BPS branch independent and stable? | explicit charges, central charges, indices and wall analysis | no stable states or no integral map |
| R70 | Which single \(\mathcal N=1\) architecture survives? | parity, tadpole, flux and correction matrix with one selected branch | no complete branch passes |

The Fano plane is not scheduled before an explicit set of seven physical
charges and maps exists. Dark matter and dark energy are separate later
phenomenology projects, not inputs to R66–R70.
