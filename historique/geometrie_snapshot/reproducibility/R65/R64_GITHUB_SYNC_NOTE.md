## Constat

Le README public présente encore dès son introduction :

- une dimension mésoscopique de \(8.2\,\mu\mathrm m\) comme caractéristique
  du cadre ;
- une série complète avec des « preuves certifiées » ;
- les huit anciens articles comme paquet scientifique consolidé.

Ces formulations ne reflètent plus le registre R63–R64 :

- \(8.2\,\mu\mathrm m\) n'est pas dérivé du modèle ;
- \(R(t)\) et le spectre KK ne sont pas calculés ;
- la tour fermée propre \(C_4\) est obstruée dans le cadre R64 ;
- le polytope résolu est déjà répertorié ;
- plusieurs claims des anciens articles doivent être retirés ou reclassés.

## Action requise avant toute nouvelle diffusion

Le README public doit être remplacé par une page d'archive clairement
historique. Son premier paragraphe devrait dire, en substance :

> Ce dépôt archive la version initiale DDF I–VIII. Après audit R1–R64, la
> construction Tyurin explicite reste le noyau validé. La relation métrique
> \(R(t)\), la valeur \(8.2\,\mu\mathrm m\), la stabilisation et les tours
> physiques ne sont pas dérivées. Les anciens articles ne doivent pas être
> cités comme résultats validés sans le registre d'errata.

Il faudra ensuite :

1. ajouter un lien vers le futur dossier audité R63–R64 ;
2. déplacer la valeur \(8.2\,\mu\mathrm m\) dans une section « ancien
   benchmark, non dérivé » ;
3. remplacer « certified proofs » par une description limitée des scripts de
   reproduction ;
4. signaler explicitement la décision arXiv et l'interdiction de resoumission
   directe ;
5. figer l'ancienne série comme archive, sans la supprimer ;
6. publier le nouveau manuscrit dans une branche ou un répertoire séparé,
   après fermeture des portes Article 1.

## Pourquoi aucune modification n'a été poussée

R64 produit un dossier local audité, pas encore le manuscrit de remplacement.
Modifier immédiatement le dépôt public rendrait visible un état transitoire
et pourrait être interprété comme une nouvelle soumission scientifique. La
synchronisation GitHub doit suivre la validation humaine et la décision
explicite de publication du nouveau paquet.
