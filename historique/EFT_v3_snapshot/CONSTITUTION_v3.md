# DDF v3 — CONSTITUTION (R0 de la version 3)
Date : 05/09/2026. Ce document fixe **avant tout calcul** ce qu'est le modèle v3, ce qui y est cité, ce qui y est dérivé, ce qui y est posé, et comment chaque pièce meurt. Il gouverne le dépôt GitHub v3 et ses 1–3 articles.

## 0. Ce que v3 n'est pas
- Pas une prédiction de R = 8,2 μm. R est **hérité de Λ** par le scénario de la dimension sombre [Established, Montero–Vafa–Valenzuela] et **validé** par ses juges (radion, tour KK), jamais dérivé d'un Casimir.
- Pas une explication de l'énergie sombre. Λ est une **entrée** (E2 de la carte des mécanismes).
- Pas une théorie qui utilise le radion comme matière noire. Le radion est **la signature**, réglée au niveau de R.

## 1. Le modèle (action maîtresse, inchangée depuis A1 ; R9 s'applique à chaque terme)
- Bulk M₄ × [0, L], frontières physiques (intervalle, pas orbifold), SM sur la brane y = 0.
- Gravité 5D + GHY ; stabilisateur σ (réel, masse m_σ, sources de brane **linéaires** J_i) ; champ de bulk Φ complexe, U(1)_D approximative, N_Φ = 2, self-interaction |Φ|⁴.
- Branes : −∫√−γ [T_i + J_iσ + U_i(|Φ|)] + L_SM en y = 0.
- **Nouveau en v3 (déclaré)** : la branche « stabilisation forte » βL ∈ [0,4 ; 0,9] est ouverte — hors des plafonds v1 (linéarité < 1 %, βL < 0,143, βL < π/8), qui étaient des choix de modélisation et non des limites physiques. La constitution v1 reste un cas particulier (βL ≤ 0,143).

## 2. Paramètres sans dimension (R2 hérité)
x = m_σL, r = m_σ/m_Φ, ε = βL, η = 2Λ₅/q², b̂ = gq/m³, plus le couplage de brane g₅ de Φ. **Aucun scan en R ou λ_r directement.**

- Phénoménologiques : signal complet Δ(r) = α_r e^{−r/λ_r} + (8/3)Σe^{−nr/R} contre la réponse publiée ou sa digitisation officielle (X-6b) ; seuils pré-enregistrés vert < 1/3, rouge > 3.
- Galactiques : RAR à zéro paramètre (a₀ = cH₀/2π) ; binaires larges (Paper I, publié) ; amas (phase mixte).
- Collisionneur : LHCb #109/#110 → borne sur g₅ côté quark b (test partiel de U-1), lacune « production prompte » déclarée.
- Interdits : littérature comme juge de stabilité ; ajustement post-hoc ; ajout de champ pour sauver un verdict (R9).
