# Lire et utiliser cette version

Pour comprendre le modèle, lire [THEORIE_DDF.pdf](THEORIE_DDF.pdf). Pour examiner les corrections, lire [l’audit de complétude](AUDIT_CORRECTIONS_ET_COMPLETUDE.md). Pour l’article, ouvrir [le manuscrit](publications/article_1/manuscript.pdf), puis [la réponse à l’avis](audits/REPONSE_AVIS_ARTICLE1.md). Pour poursuivre, utiliser [le programme de développement](DEVELOPPEMENT.md) et [la reproduction](REPRODUCTION.md).

Le registre à la racine est le seul actif. La branche principale du même dépôt DDF-Stabilized-5D-Radion contient uniquement la dernière édition corrigée. Les registres sources et les sorties de rejeu conservés sous `audits/` documentent les corrections. Les anciennes éditions complètes et les archives reçues restent sauvegardées localement, hors de l'arbre publié.
